# ShreeBalaji Naksha AI — Phase 1

Professional 2D architectural-editor foundation.

## Included
- Plot setup with exact feet/inch dimensions
- North/facing/road metadata
- CAD-style grid, pan and zoom
- Select, wall, room, door, window, staircase and dimension tools
- Move/resize selected objects
- Object properties
- Layers
- Undo/redo
- Multiple floors
- Save/load project JSON
- SVG export
- Basic geometry validation
- Architecture designed for Phase 2 Vastu + AI and Phase 3 engineering rules

## Run
```bash
npm install
npm run dev
```

Open the local Vite URL.

## Important
This is a design-engine foundation, not a code-compliance certificate or structural approval. Phase 3 will add jurisdiction-specific rules and professional review workflow.
